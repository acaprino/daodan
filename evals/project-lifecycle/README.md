# Lifecycle behavioral evals

Development assets, never shipped. Execute each case with a fresh agent on a
disposable, exclusively owned fixture. Give the agent the prompt and fixture
without exposing scoring assertions. Preserve the requested scope, installed
host and versions, baseline/candidate binding, native reports, commands/results,
file diff, required checks and retained evidence.

Score each assertion pass, fail or not exercised. A missing execution is not a
pass. Compiler tests and helper regressions are separate evidence from live
workflow execution. Record that distinction in RESULTS.md.

| Case | Path | Invariant |
|---|---|---|
| partial-assessment | assess | Missing documentary worker and incomplete X-ray coverage remain explicit gaps |
| contradicted-intent | assess, change | Existing implementation does not silently become authoritative intent |
| stale-candidate | verify | Old green CI cannot validate dirty, untracked or non-Git candidate inputs |
| protected-retention | consolidate | Summary preserves failed attempts and retained evidence before authorized disposal |
| ownership-boundaries | repair | Oracle fixes, application subtraction and semantic refactor use their canonical owners |
| proportional-change | change | Small authorized change reaches verified delivery without a blanket full audit or test quota |
| unified-stack-review | verify, review | One candidate and delivery ledger include applicable stack review and failed dimensions |
| global-rationalization | change, verify | Broad refactoring starts with current full static context and preserves suite and instruction consequences |
| first-use-choices | first use | Only the analysis depth is asked, once, before any write, and honored; a bare `.daodan/` or a decline marker does not end first use |
| records-off-cycle | change, repair | On a project that declined decision records the run's intent is the single oracle and nothing mentions records; `record-decision` turns them back on |
| records-in-brainstorm | brainstorm | Whatever brainstorming method runs, each settled decision becomes a `Proposed` record under `docs/adr/` on a project keeping records, an undecided project is asked once, a declined one never, and foreign records are never written |

Run host probes against actual installed packages when available. Adapter
rendering alone cannot demonstrate an external upstream skill was available.
