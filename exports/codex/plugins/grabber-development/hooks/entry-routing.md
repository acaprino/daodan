# Entry routing: grabber-development

These lines are the entry workflows and knowledge of the `grabber-development` plugin. A request that matches a line runs through that entry before other work. A workflow or skill entry is invoked with the host's skill or command mechanism; an entry marked "agent to dispatch" is dispatched as an agent.

- `instagram-grab-workflow`: TRIGGER WHEN: downloading, archiving, mirroring or backing up media from an Instagram profile.
