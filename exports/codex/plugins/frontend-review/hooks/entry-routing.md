# Entry routing: frontend-review

These lines are the entry workflows and knowledge of the `frontend-review` plugin. A request that matches a line runs through that entry before other work. A workflow or skill entry is invoked with the host's skill or command mechanism; an entry marked "agent to dispatch" is dispatched as an agent.
