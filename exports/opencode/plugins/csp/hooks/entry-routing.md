# Entry routing: csp

These lines are the entry workflows and knowledge of the `csp` plugin. A request that matches a line runs through that entry before other work. A workflow or skill entry is invoked with the host's skill or command mechanism; an entry marked "agent to dispatch" is dispatched as an agent.

- OR-Tools, CP-SAT, constraint solver, scheduling optimization: `csp:or-tools-expert` (agent to dispatch)
