# Entry routing: typescript-development

These lines are the entry workflows and knowledge of the `typescript-development` plugin. A request that matches a line runs through that entry before other work. A workflow or skill entry is invoked with the host's skill or command mechanism; an entry marked "agent to dispatch" is dispatched as an agent.

- TypeScript, tsconfig: `typescript-development:typescript-write`
- Zod, TypeScript generics: `typescript-development:mastering-typescript`
- knip, unused exports: `typescript-development:knip`
- type safety, any type: `typescript-development:type-safety-rules`
