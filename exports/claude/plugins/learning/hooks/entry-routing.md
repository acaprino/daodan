# Entry routing: learning

These lines are the entry workflows and knowledge of the `learning` plugin. A request that matches a line runs through that entry before other work. A workflow or skill entry is invoked with the host's skill or command mechanism; an entry marked "agent to dispatch" is dispatched as an agent.

- `/learning:export-to-markmind`: TRIGGER WHEN: the user asks for a MarkMind mind map, a mappa mentale for Obsidian, or an Obsidian-compatible concept map.
