# Entry routing: research

These lines are the entry workflows and knowledge of the `research` plugin. A request that matches a line runs through that entry before other work. A workflow or skill entry is invoked with the host's skill or command mechanism; an entry marked "agent to dispatch" is dispatched as an agent.

- `/research:science-mode`: Read or change the project's Science Mode; default ON, explicit on/off, empty input reports status.
- `/research:science-research`: Research a concrete problem through academic sources and publish a traceable scientific record.
- `/research:team-research`: TRIGGER WHEN: the user asks for a deep multi-source web research report on a topic.
- `/research:update-research`: Recheck scientific research, preserve revision history and identify superseded evidence and affected decisions.
- scientific papers, arXiv, literature review, articoli scientifici, letteratura scientifica: `research:science-based-approach`
