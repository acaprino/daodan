# Entry routing: python-development

These lines are the entry workflows and knowledge of the `python-development` plugin. A request that matches a line runs through that entry before other work. A workflow or skill entry is invoked with the host's skill or command mechanism; an entry marked "agent to dispatch" is dispatched as an agent.

- Python: `python-development:python-engineer` (agent to dispatch)
- pytest: `python-development:pytest-patterns`
- Pydantic: `python-development:pydantic-v2`
- uv, pyproject.toml: `python-development:uv-package-manager`
- asyncio: `python-development:async-python-patterns`
- PyPI, wheel, Python packaging: `python-development:python-packaging`
- Python profiling, Python performance: `python-development:python-performance-optimization`
