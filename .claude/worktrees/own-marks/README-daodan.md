# Pittogrammi cloud Daodan

[Confronta le 90 coppie nell’anteprima](preview-daodan.html). Ogni riga mostra il simbolo a 24 e 48 px. Il secondo fondo è antracite.

La griglia è di 24 × 24 unità. Il pannello bianco ha raggio 5 e bordo grigio da 1 unità. Il tratto magenta alla quota 22 misura 5 × 0,75 unità. Il disegno occupa una zona ottica di circa 16 × 16 sopra l’accento. I contorni hanno spessore 1,4 e terminali e giunzioni tondi. Le campiture hanno un filetto dello stesso colore da 0,45 per ammorbidire i vertici. I fondi AWS riprendono il colore di categoria e sostengono i segni bianchi. Per Azure e Google Cloud le tinte sono campioni piatti dell’originale.

La selezione usa i 90 ID di `list.json` presenti anche in `originals/`. La tabella indica i colori del motivo, oltre ai tre colori comuni della tessera. Il bianco scritto per nome in alcuni originali è riportato in HEX.

## Controllo ripetibile

Nel container Daodan, dalla cartella del catalogo, esegui il seguente comando.

```sh
python - <<'PY'
from collections import Counter
from pathlib import Path
import json, re
from xml.etree import ElementTree as ET
ids={x['id'] for x in json.loads(Path('list.json').read_text()) if x['id'].startswith(('aws','azure','gcp'))}
originals={p.stem:p for p in Path('originals').glob('*.svg')}
files={p.stem:p for p in Path('svg-daodan').glob('*.svg')}
assert set(files)==ids.intersection(originals)
assert Counter(k.split('.')[0] for k in files)==dict(aws=47,azure=14,gcp=29)
NS='{http://www.w3.org/2000/svg}'
old={n.get('d') for p in originals.values() for n in ET.parse(p).iter() if n.get('d')}
tags=set('svg g path circle ellipse rect line polyline polygon'.split())
attrs=set('viewBox x y width height rx ry d cx cy r x1 y1 x2 y2 points fill stroke stroke-width stroke-linecap stroke-linejoin'.split())
def hexes(raw):
    return {h.lower() if len(h)!=4 else '#'+''.join(c*2 for c in h[1:].lower()) for h in re.findall(r'#[0-9a-fA-F]{3,8}\b',raw)}
motifs=set()
for k,p in files.items():
    raw=p.read_text()
    assert p.stat().st_size<4000 and '<!' not in raw and '<?' not in raw
    svg=ET.fromstring(raw)
    assert svg.attrib=={'viewBox':'0 0 24 24'} and svg.tag==NS+'svg'
    assert len(svg)==3 and 1<=len(svg[2])<=4
    signature=tuple((n.tag,tuple((a,v) for a,v in n.attrib.items() if a in {'d','cx','cy','r'})) for n in svg[2])
    assert signature not in motifs,k
    motifs.add(signature)
    for n in svg.iter():
        assert n.tag.startswith(NS) and n.tag[len(NS):] in tags and n.attrib.keys()<=attrs,k
        assert not (n.text or '').strip() and not (n.tail or '').strip()
        assert n.get('d') not in old,k
        assert all(not re.search(r'url\s*\(|https?:|javascript:',v,re.I) for v in n.attrib.values())
    assert hexes(raw)<=hexes(originals[k].read_text(encoding='utf-8-sig'))|{'#ffffff','#e1e1e1','#ba2379'},k
doc=ET.parse('preview-daodan.html')
assert len(doc.findall('.//article'))==90 and len(doc.findall('.//'+NS+'symbol'))==180
# The eight SVG viewports per card are written in HTML, outside the SVG namespace in XML.
assert all(len(card.findall('.//use'))==8 for card in doc.findall('.//article'))
assert len(doc.findall('.//use'))==720
print(f'90/90 SVG, XML valido, massimo {max(p.stat().st_size for p in files.values())} byte.')
print('0 elementi o attributi vietati, 0 tracciati originali identici, 0 colori fuori palette.')
print('90 disegni distinti, 180 simboli incorporati e 720 campioni.')
PY
```
