# Research index

Scientific and technical knowledge supporting project decisions. Consult the
relevant source, its applicability and verification limits before reusing a
claim. New versioned research is maintained by
[science-based-approach](../../plugins/research/skills/science-based-approach/SKILL.md).
Science Mode defaults ON; its persisted project preference controls automatic
consultation and research. Explicit research commands remain available when OFF.

Search related existing Markdown before creating research, including unindexed
files. A returning topic reuses its current document; new evidence updates that
same file, research timestamps, visible supersession and descriptive changelog.
Only a distinct question creates a new current page. History is kept separately.
