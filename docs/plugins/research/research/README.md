# Base documentale della funzionalità scientifica

Questa pagina registra fonti di interoperabilità, non uno studio empirico
sull'efficacia della skill. Non è stato condotto un benchmark di accuratezza
scientifica durante l'implementazione.

| Fonte | Autore / tipo | Lettura e contributo | Limite |
|---|---|---|---|
| [Hooks](https://learn.chatgpt.com/docs/hooks) | OpenAI, documentazione tecnica | Sezioni su plugin, fiducia, input/output ed eventi; formato Codex | Non prova l'esecuzione dell'installazione dell'utente |
| [Hooks reference](https://code.claude.com/docs/en/hooks) | Anthropic, documentazione tecnica | Sezioni di registrazione e SessionStart/UserPromptSubmit; contratto Claude | Non prova altri host |
