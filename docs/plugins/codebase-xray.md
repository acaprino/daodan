# Codebase X-ray compatibility plugin

Retains the former `codebase-xray` commands, method and five worker identities.
Its required provider is [Codebase Map](codebase-map.md); both identities use
one implementation and write `.codebase-map/`. Existing invocation arguments,
including `--depth=lite`, stay valid.

Before reading or creating output, updated entries run the project-bound
[migration and path resolver](../codebase-map-migration.md). Idle
`.codebase-xray/` stores migrate without changing analysis evidence bytes.
Active runs or competing archives block migration; no archive is silently
merged or overwritten. Raw paths into older installed caches are not aliases.
