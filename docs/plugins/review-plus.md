# Review Plus

Extended correctness review adds React performance, TypeScript type safety and
platform specialists to universal review. Its code-review, team-review and pr-review
entries load `review-plus:extended-review-method`, prepare one shared input set,
dispatch signal-selected owner-qualified roles and supply their accounted results
to the canonical senior-review methods.

The core engine, finding validation, provenance, consolidation and fix loop remain
single-source senior-review behavior. Review Plus contains no copied reviewer
prompts and no second correctness engine. All three specialist providers are
mandatory dependencies. A nonmatching project signal records a skipped dimension;
a matched specialist that fails remains a failed delivery with degraded coverage.
Core and extension findings pass through one consolidation, verification panel
and final report.

Use senior-review for universal correctness alone; use Review Plus for the extended
dimensions included in senior-review before marketplace 30.0.0.
