# Skill Catalog

Skill Catalog searches the knowledge actually available to a host and selects it
for an evidenced task scope. It is shared infrastructure for review, development,
testing and documentation. Senior Review is its first automatic consumer.

The compiler ships a compact metadata registry; adapters explain how to intersect
it with actual installed/project skill bindings. Discovery reads only bounded
frontmatter and SKILL.toml, then preparation reads and fingerprints selected bodies.
It supports new languages, frameworks and domains through each skill's own metadata.
Adding knowledge needs no new reviewer or central stack-selection table.

Knowledge is a fingerprinted per-run input. Required methods and specialist roles
keep their static provider dependencies. Selected content is mandatory for its run;
missing, stale or undelivered knowledge remains failed/incomplete coverage. There is
no automatic install, workflow execution, permission expansion or second report.

Unannotated external skills are searchable but require classification at their owner
before automatic selection. Catalog candidates and static compiler tests do not
prove installed coverage. See [host bindings](../hosts.md) and the registered method.
