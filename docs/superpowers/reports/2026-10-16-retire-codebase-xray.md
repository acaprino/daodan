Verification date: 2026-10-16 (Europe/Rome). Marketplace candidate: `34.0.0`.
The canonical `codebase-map` kernel remains `6.5.3`.

## Source and scope

The authoritative remote is `https://github.com/acaprino/daodan.git`.
`git ls-remote` verified that HEAD, master and tag `v33.5.3` all identified
`2a4829ebeaf4aa3de1171b7c8d6332e5f2ed2c95`. No push or release publication is
part of this change.

The compatibility kernel, its documentation page and all five hosts' old command,
method and role registrations are removed. Codebase Map is the only analysis
plugin identity. Historical `.codebase-xray/` reports, relocation records and
existing `xray_path` data contracts remain readable through the canonical helper.
No stored evidence bytes, run IDs, snapshots or citations are rewritten.

An independent concurrent MCP change is present in the working tree. Its kernel,
new files, compiler wording and tests are not inputs to this candidate. They are
preserved outside this commit.

## Exact-source verification

A session-only read-only Git projection supplied the official loader, validators,
renderer and catalog generator with the immutable regular blobs from the verified
revision. The candidate differs only by removal of the compatibility kernel and
the marketplace version. The compiler also includes the tested publication retry
needed after repeated Windows sharing violations on the root Pi manifest.

The projection reads Git objects in a single batch, accepts only regular Git
file modes, preserves path spelling, rejects case collisions, and retains the
official path/link checks. Missing retired baseline paths use the regular-file metadata recorded by
Git. Generated bytes, package inventories and provenance are captured only in RAM.
The separately loaded skill-catalog runtime also comes from the same Git revision.

Before rendering the removal, all five complete host exports matched their
committed originals: **4,766 rendered content/catalog/loader files** and **220
original publisher lock controls**, 4,986 files in total. The locks are preserved
controls, not recompiled content.

The removal candidate contains 4,901 files including those controls. It removes
85 generated compatibility files and changes exactly ten generated files: the
five host catalogs and their five skill-metadata catalogs. No concurrent MCP
content or registration is included.

`38e973e89c20e47c11cac27d2268a33a31010fa568197ed551454d4612be9019`

Publication uses the official atomic file publisher only for the ten changed
artifacts, under all existing official per-package OS locks. Unchanged content
reuses the original Git bytes already proved equal to the complete render. It preflights every destination and directory, refuses
unknown or concurrent generated files, retires only packages whose provenance
