# Daodan 1.1.0

Daodan ships the standalone analysis app and graph explorer in the Python package. Both interfaces use Imago for their controls, layouts and styles. The explorer supports navigating from modules down to functions. The SmoothUI prototype has been removed.

Run `daodan app` to open the standalone app, or `daodan mcp` to start the MCP server. Both commands use the same installed application. See the [installation instructions](../../README.md#install).
