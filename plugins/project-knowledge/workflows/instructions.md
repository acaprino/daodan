# Instructions

Load `project-knowledge:instructions-method` and execute its canonical method for
`$ARGUMENTS`. Reuse a caller's owned run and authorizations; otherwise initialize
one through `project-protocol:project-protocol`. Select the authoritative host/project destination before dispatching instructions-auditor. Audit-only is the default; reuse existing authorization for application.

Preserve native reports, source/intent distinctions, snapshot identity and
unavailable checks. Do not repeat detector prompts or treat another run's report
as current knowledge. Record delivered/failed explicitly and validate the result
through the protocol before declaring completion.
