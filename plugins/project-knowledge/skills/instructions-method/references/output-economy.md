# Context and output economy

Use when a project's instruction plan calls for efficiency guidance. Equivalent
local guidance remains valid. Add only obligations supported by the project's
workflow and available tooling; a pointer does not prove automatic loading.

For projects authoring skills, agents, tools or other agent components, apply
the Authoring components section of the loaded `work-controller:work-record`
skill. The instruction plan names how produced components and their workers
receive applicable rules, with domain-appropriate verification for any language,
framework or activity. Verify that consumption path rather than assuming the
project's instructions accompany independent deliverables.

Keep always-loaded instructions focused on durable obligations. Put detailed
procedures and templates in working references, loaded when the active step
requires them. Length alone does not establish that a rule can be deleted.

Use targeted searches and bounded tool output. Expand to complete definitions,
call sites or files whenever needed to establish evidence. Preserve every
mandatory read, independent premise verification and declared coverage dimension.

Produce each result once in its owner's canonical format. Link detailed artifacts
from summaries rather than copying their contents. Keep native reports,
provenance, uncertainty and unknown values intact. A compact summary is a view,
never replacement evidence or permission to close a missing delivery.

Reuse existing templates and deterministic renderers for recurring human views.
Agents supply domain content; code supplies layout, interactions and derived
values. Keep presentation code out of worker handoffs unless the task edits it.
Use a visual view when it helps comparison, navigation or a decision. A missing
renderer is an implementation requirement, never a reason to claim that a
textual instruction supplies one. Resolve any selected provider through its
registered skill and the consumer's declared required dependencies.

Record token usage only when receipts or host measurements exist. Distinguish
generation, edits and downstream reads, and compare equivalent content and
capabilities. Unknown usage stays unknown; shorter prose alone proves no saving.
