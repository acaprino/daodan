# Investigation and debug handoff

Load `senior-review:investigation-method`. Preserve its observed facts, map or
search perimeter, independent hypotheses, reproduction and verdict. Investigation
writes no product code and never converts a hypothesis into a requirement.

A demonstrated cause with a reproduction can continue into `references/repair.md`
or `references/change.md` when the user requests the fix. Close the investigation
run, carry its exact report and failing test into the new run as the oracle, then
follow the normal specification, adversarial plan and commit gates. A probable or
open verdict remains visible; ask for the missing evidence instead of starting an
ungrounded fix.
