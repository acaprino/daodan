# Academic discovery and reading

Choose source families by discipline, not by a fixed exclusive allowlist.
Use the session's search/fetch tools with site restrictions, exact titles/DOIs,
synonyms and relevant version/date filters. Do not put confidential code or
user data into public queries.

| Family | Useful starting points | Interpretation |
|---|---|---|
| Cross-disciplinary discovery | [Semantic Scholar](https://www.semanticscholar.org/), [OpenAlex](https://openalex.org/) | Find identities and citation links; open the primary work |
| Computing, ML, NLP | [arXiv](https://arxiv.org/), [PMLR](https://proceedings.mlr.press/), [ACL Anthology](https://aclanthology.org/), [OpenReview](https://openreview.net/) | Distinguish preprint, submission and published version |
| Other disciplines | Relevant publisher/repository; [PubMed](https://pubmed.ncbi.nlm.nih.gov/) and [PMC](https://pmc.ncbi.nlm.nih.gov/) for biomedical work | Index records are not full-text reading |
| Identity and editorial notices | Publisher/DOI landing page, [Crossref](https://www.crossref.org/), [Crossmark](https://www.crossref.org/services/crossmark/), [Retraction Watch](https://retractionwatch.com/) | Missing notice is not proof of validity |
| Technology applicability | Official versioned docs, standards and maintainer release notes | Documentary evidence, listed separately from papers |

Search in useful rounds: precise question and terminology; foundational and
recent results; citations/replications; conflicting results and editorial notices.
No paper quota. Mirrors, versions and studies sharing one dataset do not count as
independent replication. Include/exclude by relevance, methods and applicability,
not by agreement with a preferred answer.

For each source retain stable ID, authors, title, year, venue, DOI or equivalent,
primary link, version/access time, concise synopsis, methodology and limitations.
Reading status is full-text, selected-sections (name them), abstract-only,
metadata-only or unavailable. A truncated PDF is not full-text. Locate each
supported claim by section/page/table; never extrapolate beyond the read material.
Summarize rather than reproducing copyrighted full text.

A failed lookup is a recorded gap. Try an available legitimate primary mirror or
repository, then continue with honest limits. Never invent access, metadata,
measurements, retractions or a successful literature check.
