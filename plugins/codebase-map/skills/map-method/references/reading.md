# Reading an analysis

## Producer views

Generate `semantic-map.md` with `semantic_map.py MANIFEST --path AREA`; unread/stale
cards use `deepen.md`. Bounded, resumable LLM input: `context.md`. Preserve provenance.

## Task views

The report's `Quick Reference: Which File to Consult` table (skeleton in
`phase-7.md`) names the files to start with per task. Phase 0's `knowledge/`
holds unverified leads: `documentation-leads.md` for concepts, `navigation.md`
for the project's own indexes. To locate the code of a change follow `locate.md`.
