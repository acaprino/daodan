# Document quality

Design for the reader's task: what they need to learn, decide or do. Put the main
message early and let headings explain the argument. Match the supplied brand or
template, audience, language and locale; professional formatting is coherent and
readable, not a fixed paper size or ornamental cover.

| Element | Useful default | Verification |
| --- | --- | --- |
| Structure | Native heading levels and a clear section order | Navigation and any TOC reflect the document |
| Typography | A restrained font system with distinct title, heading and body styles | Text is legible and hierarchy remains consistent |
| Paragraphs | Style-based spacing and deliberate keep-with-next rules | Headings stay with their text and no awkward gaps appear |
| Lists | Native bullets or numbering with consistent indentation | Continuation and nesting match the intended meaning |
| Tables | Native cells, meaningful headers and readable widths | Columns fit, repeated headers work and splits remain legible |
| Images | Native image objects with preserved proportions, captions and alternative text | Images are sharp, aligned and anchored appropriately |
| Sections | Appropriate paper, margins, orientation and header/footer variants | Page breaks and header/footer content match each section |
| References | Supported native fields, bookmarks and citations | References resolve and updated results match their targets |
| Existing content | Scoped edits that retain unaffected runs and package features | Comments, revisions, links and advanced objects survive correctly |

Use actual source figures and give assumptions a visible home. Tables and charts
need units and readable labels. Provide sources where the reader needs to evaluate
a claim. Alternative text describes an image's purpose; decorative content should
not interrupt reading where the engine supports that distinction.

Review rendered pages from the saved DOCX, including the cover, dense tables,
section transitions and the final page. Inspect every page for a finished short
document. For a long document, review the complete page sequence for anomalies and
inspect representative and changed pages in detail. State that review scope.
Package checks establish structure; an actual compatible render establishes the
observed layout. Field-update flags and cached pagination establish neither.
