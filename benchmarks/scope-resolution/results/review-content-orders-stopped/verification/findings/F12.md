# F12: The ledger's location depends on the process working directory

- Severity: Medium
- Confidence: 75
- File: `benchmarks/scope-resolution/app/packages/orders/ledger.py`
- Line: 5
- Description and evidence: `Path("ledger.log")` and `Path("ledger.lock")` resolve against the cwd at each call, with no configured root. A service started elsewhere silently opens a new empty ledger: the accounting history forks, and locks in separate directories do not exclude each other.
- Suggested fix: Resolve one absolute ledger root once, from configuration, and derive both paths from it.
- Load-bearing premise: the authoritative ledger location depends on the working directory of the process.
- premise_provenance: independent
- Trigger: Two invocations or a restart with a different working directory, or os.chdir in-process.
- Counterevidence checked: No other assignment of LEDGER_PATH or LOCK_PATH in app/; no chdir in app/; no environment override; the deployment working directory is undeclared.
- introduced_by_candidate: not applicable on content basis
- evidence_class: derived
