# F21: `_LOCKS` keeps one entry per sku value forever, even for skus refused

- Severity: Low
- Confidence: 70
- File: `benchmarks/scope-resolution/app/packages/orders/inventory.py`

- Description and evidence: `_LOCKS.setdefault(sku, threading.Lock())` runs before the stock check, keyed by the payload's sku, with no removal. Process memory grows slowly with each new distinct sku value, with no error.
